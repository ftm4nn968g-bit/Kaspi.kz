# Маркетплейс: Тапсырыстар мен Қойма (Kaspi.kz үлгісінде)

Бұл жоба Kaspi.kz сияқты маркетплейстің тапсырыстарды өңдеу және қойма қалдықтарын басқару жүйесін Java тілінде модельдеуге арналған.

## Команда мүшелері
 Аяжан,Тoгжан

## Жобаның мақсаты
Тапсырыстарды қабылдау, өңдеу, қойма қалдықтарын басқару және бір уақытта түскен сұраныстарды (Concurrency) дұрыс өңдейтін сенімді backend жүйесін құру.

## Технологиялар
* Java 21
* Maven
* SQLite (JDBC)
* JUnit 5
* Stream API
